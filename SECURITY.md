# Security Policy

## Supported versions

Security fixes go into the latest release only. Please check that a problem still happens there before reporting it.

## Reporting a vulnerability

Please report vulnerabilities privately through [GitHub's private vulnerability reporting](https://github.com/JacksonDam/FirstRow/security/advisories/new), not in a public issue. Include:

- the First Row version and platform
- steps to reproduce
- what an attacker could do with it

First Row is maintained by one person, so replies are best effort. Please give a reasonable amount of time for a fix before disclosing the problem publicly.

## Scope

In scope: the First Row app and the code in this repository.

Out of scope: the services and servers First Row connects to (media servers, streaming services and LRCLIB), and the open source libraries it ships with. Report those to their own maintainers, unless the problem is in how First Row uses them.
